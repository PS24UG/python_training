# Python Programming Tasks & Exercises

This repository contains basic to intermediate Python scripts covering logical thinking, loops, string operations, math utilities, and mini-applications.

## 🚀 Tracked Tasks

### 1. Basic Conditionals
* **Loan Eligibility Check:** Verifies loan requirements based on salary and age.
* **Even/Odd & Divisibility:** Checks basic numeric conditions.

### 2. Mini Application
* **ATM Menu System:** Simulates safe withdrawal (with denominations) and deposit functions.

### 3. Strings & Patterns
* **Pattern Programs:** Right triangle and inverted patterns using loops.
* **Vowel Counter & Palindrome:** Practical applications of string slicing and iteration.
