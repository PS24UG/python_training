# Python Programming Basics & Mini Projects

This repository contains a structured collection of Python scripts covering basic fundamentals, conditional logic, loops, string manipulation, pattern printing, and a simulated ATM application. It serves as a practical guide for mastering core Python concepts.

---

## 🚀 Repository Structure & Topics Covered

### 1. Basic Conditional Tasks (`Basic_Conditionals/`)
* **Loan Eligibility Check:** A nested condition program that checks if a user is eligible for a loan based on salary and age restrictions.
* **Even or Odd Checker:** Determines whether a given number is even or odd using the modulus operator.
* **Divisibility Test:** Checks if a number is simultaneously divisible by both 3 and 5.

### 2. Loops and Arithmetic Problems (`Loops_and_Arithmetic/`)
* **Even/Odd Sequences:** Scripts to filter and print specific number ranges.
* **Multiplication Table Generator:** Dynamically prints the mathematical table for any user-inputted number.
* **Sum and Range Counters:** Calculates cumulative sums, counts specified criteria, and filters numbers divisible by 3 and 5 within a range (1–100).

### 3. General Mathematical Programs (`Math_Programs/`)
* **Speed Limit Monitor:** A simple road safety logic that triggers an over-speeding penalty ticket if the speed exceeds 70.
* **Sum of Natural Numbers:** Prints numbers from 1 to N and displays their mathematical sum.
* **Cube Generator:** Loops through numbers up to N and prints the cubic value ($i^3$) of each number.
* **Factorial & Prime Checker:** Includes optimized loops to find the factorial of a number and determine whether a given number is Prime or Not Prime.

### 4. String and Number Utilities (`Utilities/`)
* **Digit Counter:** Calculates the exact number of digits in an integer safely (handling negative values).
* **Number Reversal:** Uses Python's powerful string slicing `[::-1]` to instantly reverse any input number.
* **Vowels & Consonants Counter:** Iterates through a string to separate and count alphabets (ignoring spaces and special characters).
* **Palindrome Checker:** Validates whether a text reads the same backward as forward.

### 5. Pattern Printing (`Patterns/`)
* **Right Triangle Pattern:** Generates a progressive numerical right-angled triangle.
* **Inverted Right-Aligned Star Pattern:** Implements nested loops using spaces and asterisks (`*`) to print a clean, right-aligned inverted triangle.

### 6. ATM Menu System (`ATM_Project/`)
* **Mini Banking Application:** A console-based application utilizing Python's `match-case` syntax. Features include:
  * Balance Inquiry.
  * Smart Cash Withdrawal (with denomination validation for 100, 200, and 500 notes, along with automated balance updates).
  * Deposit Management.
